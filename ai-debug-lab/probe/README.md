# Native probe 0.3.0 (Fabric 26.2)
Build with Java 25 / Gradle 9.5.1: `gradle -p ai-debug-lab/probe build`.
Install the production JAR and matching Fabric API in a test instance's mods folder. Disabled unless JVM argument `-Dmms.debug.enabled=true` is set. Optional `-Dmms.debug.overworld.pos=0,80,0`. Output is a session-specific mms-debug/<UUID>/snapshot.json under the game directory, published atomically every 100 end-tick callbacks. Registry inventory is captured at server startup, with a 20,000-entry limit per category and explicit totals. Snapshot includes observed block and optional already-present block-entity type; no NBT, player names, inventories, arbitrary commands or network listener. Only existing loaded overworld chunks are inspected; no forced chunk loading. Window elapsed is callback wall-clock interval, not MSPT. No causality or energy-network inference. Singleplayer support is architectural only until tested. The local OS account can read the evidence; do not automatically send it to remote models.

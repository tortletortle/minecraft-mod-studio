# V0.8 static mod knowledge index
Run `python ai-debug-lab/mod_knowledge.py /path/to/mods > knowledge.json`. The engine parses Fabric manifests, modern and legacy item-tag and vanilla recipe JSON from top-level JARs; outputs source-attributed resources and typed reference edges, repeated declarations and shared reference surfaces. Never executes JARs or extracts paths. Budget limits and unknown serializers are explicit. It does not claim runtime precedence, machine behavior, compatibility, or causal conflicts. Custom recipes need versioned semantic adapters. Next: link static declarations to live probe registry evidence and approved experiment templates; make tool pagination available to general IDE hosts. No front-end changes.

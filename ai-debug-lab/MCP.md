# V0.11 local MCP integration
Use official Python MCP SDK 2.3.0 (https://py.sdk.modelcontextprotocol.io/). The MCP adapter is optional and reuses the existing JSONL Bridge; install with python -m pip install -r ai-debug-lab/requirements-mcp.txt. Start with python ai-debug-lab/mcp_adapter.py --workspace /path/to/test-instance. Configure any compatible MCP host to launch this command using absolute paths. Example configuration below is generic, not a verified config for every host:
```json
{"mcpServers":{"minecraft-debug":{"command":"/path/to/python","args":["/path/to/ai-debug-lab/mcp_adapter.py","--workspace","/path/to/test-instance"]}}}
```
Five default tools only; --allow-logs adds logs_tail, --allow-rcon adds game_tick_observe (ticks and gametime only; password from MC_DEBUG_RCON_PASSWORD). Both disabled by default. No arbitrary commands, NBT, player list, world changes, automatic model calls, network MCP endpoint or autonomous agent loop. Local operator chooses a trusted workspace; raw evidence can contain sensitive data. No OS sandbox, no guarantee host keeps evidence local. MCP read-only annotations are hints; actual dispatch allowlist and typed constraints enforce policy within the adapter. Serialized diagnostic calls and 512 KiB response bound; underlying filesystem ops may take time. CI uses real SDK clients in memory and through a child process over stdio; this does not prove integration with every third-party IDE.

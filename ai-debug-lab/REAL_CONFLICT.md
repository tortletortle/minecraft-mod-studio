# V0.7 disposable Fabric trial integration

First real injected runtime interaction. Fixture Alpha transforms white wool to red wool after diamond trigger, Beta transforms red wool to obsidian. Library is required by Alpha; Noise is irrelevant. Both together produce an unexpected observed block, independent of tick-handler order after settling. Test reads actual Minecraft block predicates, waits for 40 game ticks, confirms trigger, uses two seeds and two repeats, and requires fresh candidate/control confirmations. Every trial boots a fresh temporary world, installs exact hashed JARs, records log and structured receipt, then stops its subprocess. No existing world is cloned or touched. Pinned Fabric API, explicit graph, no general loader dependency resolver. Only trusted fixture JARs should be executed: separate directories are not a security sandbox. No untrusted third-party mods, client-side mods, crash-fingerprint test or arbitrary model-generated predicate in this version. CI budget is bounded by trial count and workflow timeout; a timeout is inconclusive. Fabric launcher installation: https://wiki.fabricmc.net/install .

# V0.9 recipe diagnosis bridge

Tool: mods.diagnose_recipe, arguments {"session":"<native probe UUID>","recipe":"namespace:recipe_id"}. Reads the configured workspace mods directory and the selected native snapshot. Returns source JAR hash/path, recipe declarations, item registry presence, mod ID/version alignment, tag unknowns, and explicit unverified hypotheses. Static item references can be alternatives, and mod ID/version match is not runtime JAR identity. Unknown/truncated evidence cannot establish absence. Plan separates available snapshot reads from unsupported live recipe/tag/pack and experiment capabilities; no world writes, model integration or automated recipe repair. Unit fixtures are synthetic. The production-JAR Fabric smoke now installs an additional data-only recipe fixture referencing an actual Studio-generated item. It checks ID/version alignment, static hash, registered input/output IDs and explicit unknown tag status. It does NOT check that Minecraft actually loaded or executed the recipe; that needs an active RecipeManager adapter and a crafting test.

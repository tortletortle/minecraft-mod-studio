# V0.6 dependency-aware failure minimizer

Algorithm foundation adapted conceptually from Zeller/Hildebrandt Delta Debugging (https://www.st.cs.uni-saarland.de/dd/), not copied code. The trusted runner supplies an exact component dependency graph, pinned core, failure fingerprint, and trial oracle. Search uses dependency-preserving complement deletion, including reverse-dependency closure. Each tested candidate uses the same seed/repeat schedule; final confirmation and removal controls are fresh executions. A different crash, malformed receipt, invalid trial, or intermittent observation cannot certify a clean control. Required graph constraints and bounded trial count are explicit. No global minimum or causal inference claim.

Run `python -m unittest discover -s ai-debug-lab -p 'test_*.py' -v` from repository root. Unit scenarios are synthetic: true pair conflict, transitive dependency, invalid trials, intermittent baseline, wrong error, stale evidence, drift and hard budget. The module is an algorithm library, not yet a real modpack launcher; there is no arbitrary subprocess command provided by AI. The next milestone is a trusted runner with immutable JAR inventory, disposable per-trial instance, version-aware dependency resolver, and a real injected-fault fixture plus controls. Third-party modpack support remains unverified.
